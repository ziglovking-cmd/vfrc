# Физика — учебный сайт

Теория, тесты и листы в тетрадь. Курс: 1–4.

Сайт: https://ziglovking-cmd.github.io/vfrc/site

Отдельного домена нет. Файл CNAME в репозиторий не кладём.

Ключи для учителя и токен бота сюда не входят.

Файлы для отправки ученику лежат в `site/export/`: текст урока и текст теста без решений и без правильных ответов. Их передают вложением. После сдачи сообщают, верен ответ или нет, и итоговый счёт. Список файлов: `site/export/manifest.json`.
